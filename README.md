Entry for the [Funniest Time Machine Warning Label](https://make.fun/bounty/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151) bounty on [make.fun](https://make.fun).

`main.py` (standard library only) writes a single one-line warning label for a time machine — 94 characters, inside the 120-character limit — to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

The label, phrased as a genuine safety notice:

> WARNING: Never warn your past self about this trip. He will not listen, and you are the proof.
